# 📚 StudyPilot AI

StudyPilot is an AI-powered learning assistant built with **Next.js**, **Firebase App Hosting**, and **Genkit AI flows**.  
It helps students generate answers, revision sheets, important questions, and summaries to improve study efficiency.

---

## 🚀 Features

- 🧠 AI-powered exam answer generation
- 📄 Smart revision sheet creator
- ❓ Important questions generator
- 📝 Notes summarizer
- 📊 Student dashboard
- 🔐 Authentication system
- 💳 Usage tracking / billing system

---

## 🛠 Tech Stack

- Next.js (App Router)
- TypeScript
- Firebase App Hosting
- Genkit AI (Google AI flows)
- Tailwind CSS

---

## 📁 Project Structure

src/app → Frontend routes (UI pages)  
src/ai/flows → AI logic (Genkit workflows)  
src/components → Reusable UI components  
src/lib → Utility functions  
apphosting.yaml → Firebase deployment configuration
