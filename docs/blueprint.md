# **App Name**: StudyPilot AI

## Core Features:

- Smart Study Material Tool: Uses AI to transform raw notes or topics into summaries, bullet points, exam answers, and structured revision sheets.
- Exam Prep Generator: Generates 2-mark, 5-mark, and 10-mark probable questions from provided chapter notes using AI-driven logic.
- User Progress & Material Storage: Persists generated materials, history, and usage statistics within a cloud database.
- Plan-Based Usage Management: Gated access to the transformation engine with usage-tracking logic for Free vs Pro tiers, including integrated payments.
- Academic History Dashboard: A centralized interface to manage previously generated outputs and track learning progress.
- Identity and Session Management: Secure authentication using social logins and email, tailored for a personal dashboard experience.

## Style Guidelines:

- Primary color: Scholarly Indigo (#4351CC) for a sense of focus and academic reliability.
- Background color: Mist White (#F6F7FB), a low-saturation variant of the primary for a clean, distraction-free environment.
- Accent color: Celestial Blue (#3EA6E1) for active states, CTA highlights, and differentiation between different output types.
- Main font: 'Inter', a grotesque sans-serif used for both headlines and body text to achieve a modern, machined, and neutral look suitable for heavy reading.
- Simple, lightweight outline icons (similar to Lucide) to maintain the clean, functional Notion-inspired aesthetic.
- Side-drawer navigation for document history with a centered, spacious editor layout in the dashboard for focus-driven work.
- Gentle pulse indicators during AI generation and smooth slide transitions when switching between summaries and Q&A formats.
